# <b>EmbedFixer</b>
## Discord bot that deletes social media post messages and replaces them with embed-friendly URL equivalents
## Supports:
- Reddit (vxreddit)
- TikTok (tnktok)
- Twitter (vxtwitter)
- Instagram (kkinstagram)
- Bluesky (bskye)
- Threads (vxthreads)
